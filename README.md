## 📋 Описание проекта

Лабораторная работа №2 по программированию. Программа демонстрирует принципы объектно-ориентированного программирования (ООП) на примере системы классов автомобилей.

## 🎯 Задание

Создать программу с соблюдением принципов ООП:
- Создать базовый класс `Авто`
- Создать минимум 2 наследных класса марок авто
- Описать не менее 3 свойств объекта для каждого класса
- Реализовать 5 методов (2 с перегрузкой из базового класса)

## 🏗️ Архитектура программы

### Базовый класс `Car`

**Абстрактный базовый класс** определяет общую структуру для всех автомобилей:

#### Свойства (5):
- `brand` - Марка автомобиля (строка)
- `model` - Модель автомобиля (строка) 
- `year` - Год выпуска (целое число)
- `color` - Цвет автомобиля (строка)
- `price` - Цена автомобиля (вещественное число)

#### Методы (5):
1. `start_engine()` - Запустить двигатель
2. `stop_engine()` - Остановить двигатель  
3. `accelerate(speed)` - Увеличить скорость
4. `brake(intensity)` - Торможение
5. `get_info()` - Получить информацию об автомобиле

#### Абстрактные методы:
- `get_max_speed()` - Получить максимальную скорость (перегружаемый)
- `get_fuel_type()` - Получить тип топлива (перегружаемый)
- `get_special_features()` - Получить особые характеристики

### Наследные классы

#### Класс `BMW`

**Наследуется от `Car`** - реализует автомобили BMW:

#### Дополнительные свойства (3):
- `series` - Серия BMW (M3, 5, X5, iX и т.д.)
- `drive_type` - Тип привода (задний, передний, полный)
- `_sport_mode` - Спортивный режим (внутреннее свойство)

#### Перегружаемые методы (2):
1. `get_max_speed()` - Возвращает максимальную скорость в зависимости от серии
2. `get_fuel_type()` - Определяет тип топлива (бензин, гибрид, электричество)

#### Дополнительные методы:
- `activate_sport_mode()` - Активировать спортивный режим
- `deactivate_sport_mode()` - Деактивировать спортивный режим

#### Класс `Mercedes`

**Наследуется от `Car`** - реализует автомобили Mercedes-Benz:

#### Дополнительные свойства (3):
- `class_type` - Класс Mercedes (A, C, E, S, G и т.д.)
- `amg_package` - Наличие AMG пакета (булево значение)
- `_comfort_mode` - Комфортный режим (внутреннее свойство)

#### Перегружаемые методы (2):
1. `get_max_speed()` - Возвращает максимальную скорость с учетом AMG пакета
2. `get_fuel_type()` - Определяет тип топлива с учетом модели

#### Дополнительные методы:
- `activate_comfort_mode()` - Активировать комфортный режим
- `deactivate_comfort_mode()` - Деактивировать комфортный режим

## 🎯 Особенности реализации

### Принципы ООП:

1. **Инкапсуляция**:
   - Все свойства имеют приватные поля (`_brand`, `_model` и т.д.)
   - Доступ через property декораторы с валидацией
   - Скрытие внутренней логики работы

2. **Наследование**:
   - Базовый абстрактный класс `Car`
   - Классы `BMW` и `Mercedes` наследуют функциональность
   - Расширение функциональности в дочерних классах

3. **Полиморфизм**:
   - Перегрузка методов `get_max_speed()` и `get_fuel_type()`
   - Разная реализация в зависимости от класса
   - Единый интерфейс для разных типов объектов

4. **Абстракция**:
   - Абстрактный базовый класс с `@abstractmethod`
   - Определение общего интерфейса
   - Сокрытие деталей реализации
